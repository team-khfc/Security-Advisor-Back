# 보안성검토·정보보안 구성 편집

2026-11-11 사용자 요청에 따라 보안성검토에도 방화벽 신청과 동일한 서버·네트워크·운영 구성 화면을 제공한다. 보안성검토 고유 추가 항목은 이번 범위에 포함하지 않는다. 서류 유형과 최종 처리(보안성검토에서 실제 방화벽 규칙을 생성하지 않음)는 유지한다.

- 배정된 INFRA 또는 SECURITY 담당자만 협의 단계에서 구성 임시 저장·확인 저장 및 AI 초안을 사용할 수 있다.
- 구성 저장의 공유 항목 10개만 별도 권한 경로를 사용한다. 일반 개별·일괄 답변의 게시본 역할 정책은 유지한다.
- 실제 입력자와 이력을 저장한다. 수정 충돌·AI 미확인 차단·변경 후 재검토 및 제출본 보존은 유지한다.
- 기존 API의 요청·응답 구조 변경은 없다.

검증: 두 서류 유형의 정보보안 담당자 임시·확인 저장, AI 제안 접근, 신청자·관리자 저장 차단, 기존 답변 권한 정책, 구조 검사 통과. 실제 외부 모델 호출과 브라우저 로그인 흐름은 이번에 재검증하지 않았다.
