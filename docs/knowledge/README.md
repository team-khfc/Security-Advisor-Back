# 공개 지식 데이터 (knowledge_snippets)

각 파일은 `POST /api/knowledge-snippets`(ADMIN) body 와 같은 모양의 원소 배열이다.

| 파일 | 건수 | 출처·판본 | 본문 형태 | 확인 상태 |
|---|---|---|---|---|
| `knowledge_snippets_nis_guideline.json` | 192 | 국가 사이버보안 기본지침(국가정보원), 2026.5.1. 일부개정 | **조문 원문**(조·항 단위, 긴 조는 1,100자 안팎으로 분할) | 국가사이버안보센터 공개 PDF 에서 기계 추출. 제1조~제151조 본문 전부(삭제 조문·부칙·별표 제외) |
| `knowledge_snippets_public.json` | 15 | 개인정보의 안전성 확보조치 기준(6), KISA ISMS-P 인증기준 안내서 2023.11.(9) | 요지를 풀어 쓴 문장 | 2차 자료로 확인. 고시 번호·시행일은 원문 대조 필요 |

## 지침 파일을 만든 방법과 한계

- PDF 텍스트를 조문 단위로 자르고, 개정 이력 표기(`<개정 …>`, `[종전 … 이동]`)와 삭제된 항·호를 뺐다. 조문 문장은 고치지 않았다.
- PDF 는 줄 끝에서 낱말이 잘려 있어 줄을 이을 때 띄어쓰기를 추정했다(319곳 붙임). **낱말 중간에 공백이 남았거나 잘못 붙은 곳이 일부 있을 수 있다**(예: "통 제할"). 인용 전 `sourceLocator` 의 조·항으로 원문을 확인한다.
- `fieldKeys`: 신청서 항목과 직접 관련된 15개 조(제11~18·42·53·54·55·73·75·76조)만 항목 키를 붙였다. 나머지 175건은 `general` 이라는 자리표시 값이다 — 실제 항목 키가 아니라서 지금 서버에는 등록되지 않는다(아래 "알아 둘 제약" 1번).

## 넣는 방법

지식은 초안 → 게시 2단계다(`docs/ARCHITECTURE.md` 4장 0012). 등록은 초안에만 들어가고, 게시해야 AI 검색·항목 도움말·인터뷰에 쓰인다.
사업 건은 만들 때의 지식 게시본에 고정되므로, 게시한 뒤에 만든 사업 건부터 새 지식이 적용된다.

```powershell
.\scripts\load-knowledge-snippets.ps1 -Username <관리자 계정> -BaseUrl http://localhost:8080 -DryRun   # 건수만 확인
.\scripts\load-knowledge-snippets.ps1 -Username <관리자 계정> -BaseUrl http://localhost:8080 -DeactivateSynthetic
```

스크립트는 관리자 로그인 → 초안 중복 확인 → 등록 → 게시를 한다. **실제 서버에서 끝까지 실행해 검증한 기록은 없다.** 수동으로 하려면
`POST /api/knowledge-snippets` 로 넣고 `POST /api/knowledge-drafts/current/publications` 로 게시한다.

## 알아 둘 제약

1. **`general` 태그 조각 175건은 등록되지 않는다.** 서버는 `fieldKeys` 에 현재 설정 게시본의 실제 질문 키만 받는다. 스크립트는 기본으로 건너뛰고,
   `-GeneralFieldKey <질문 키>` 를 주면 그 키로 바꿔 넣는다(그 질문의 AI 제안 후보에 관련 없는 조문이 섞인다). 지침 전체를 담당자 질의에서 찾게 하려면
   "질문에 묶이지 않는 조각"을 허용하도록 `knowledge.service.KnowledgeValidator` 를 고쳐야 한다.
2. 마이그레이션에 들어 있는 합성 예시 6건은 `-DeactivateSynthetic` 으로 끈다(같은 항목에 합성 문장이 섞여 인용되지 않게).
3. 등록 전에 정보보안 담당자가 항목 키가 붙은 조문 17건의 띄어쓰기·내용을 원문과 대조한다.
4. `project.department` 항목에는 조각이 없다(근거가 될 공개 규정이 없음).
5. 검색은 낱말 앞부분 일치 전문검색이다. 비슷한 말("보관"/"보존")은 서로 찾지 못하므로 본문에 현업이 쓸 낱말이 들어 있어야 한다.

기관 내부 규정·비공개 지침은 이 폴더에 넣지 않는다.
