# GPT 협의 요약 근거 선택 수정

## 재현

심사용 합성 신청 06에 기존 프롬프트를 사용한 실제 gpt-4o-mini 호출에서 정상 종료(stop)한 JSON이 반환됐지만, `current.project.summary`, `current.review.logging` 등 실제 목록에 없는 키가 포함됐다. 내부 키의 접두부를 생략하거나 JSON 경로로 재조합한 것이며 출력 한도·인증 오류가 아니다. 자동으로 경로를 잘라 붙이면 서로 다른 근거를 오인할 수 있으므로 정규화로 통과시키지 않는다.

## 변경

- 기준본·현재 값의 키 합집합을 정렬해 요청별 E번호를 발급한다. 모델에는 근거 목록의 E번호와 해당 기준본/현재 값을 전달한다.
- 담당자 변경 이력의 before/after도 같은 E번호로 연결한다. 원본 키가 없는 변경 필드는 요약 근거로 사용하지 않으며 전체 이력 원본은 변경하지 않는다.
- 모델은 목록의 E번호만 선택하고 서버가 정확한 원본 키로 변환해 저장한다. API 응답·기존 저장 데이터·화면의 근거 링크 형식은 유지한다.
- 미등록 번호·내부 키 직접 반환·경로·숫자형 참조를 거부한다. 잘못된 근거를 삭제하거나 추측해 저장하지 않는다. 빈 근거·근거 없는 IP·원본 변경·출력 중단 차단도 유지한다.
- 모의 AI도 동일한 식별자 계약을 따른다. 자동 재시도를 추가하지 않는다.

## 검증

집중 회귀 검사 18건 통과: 정상 변환·중복 제거, 기준본에만 있는 항목과 담당자 이력 매핑, 미등록/잘못된 근거 거부, 원본 변경 충돌, 출력 중단 차단.

심사용 도커의 박소영 계정·합성 신청 06에서 프론트 중계를 통해 실제 gpt-4o-mini(temperature 0.2, 최대 4096토큰)를 2회 호출했다. 두 요청 모두 첫 응답에 성공했으며 각각 5항목의 근거 키가 원본에 존재하는지 확인했다. 자동 확인·제출은 수행하지 않았고 시험용 모델 우선순위·토큰 설정은 복원했다. 키와 모델 응답 원문은 커밋하지 않았다.
