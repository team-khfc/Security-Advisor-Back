# 0013. AI 모델 구성 변경 이력과 실제 연결 시험

상태: 채택 · 2026-11-10 · Back #21 / Front #54

기관 관리자는 인터뷰·문서 요약·초안 생성·담당자 질의별 모델 구성의 활성 여부와 우선순위를 조정한다. 활성·허용 호스트·설치된 키를 만족하는 구성 중 우선순위, ID 순으로 선택한다. 설치 허용 목록에서 제외된 과거 구성은 건너뛰며, 적격 모델이 없으면 사용 불가로 표시한다. 업무 시연 모드는 실제 선택과 구분한다.

## 결정

- 구성의 비교·저장·복원·연결 시험은 같은 입력 검증을 사용한다. 이름·용도·범위·허용 주소·허용 키 참조를 검증한다. URL의 사용자 정보·쿼리·fragment와 메타데이터 주소는 거부한다.
- `LLM_ALLOWED_KEY_ENVS`에 등록한 환경변수 이름만 선택할 수 있다. 관리자라도 임의의 DB 비밀번호 환경변수를 모델 키로 전달할 수 없다. API와 DB에는 실제 키를 저장하거나 반환하지 않는다. 사용자 지정 키 이름은 설치 설정에서 허용한 뒤 서버를 재시작한다.
- 저장은 적용이다. 별도의 기관 설정 게시본처럼 신청마다 모델을 고정하지 않는다. 이후 AI 호출에 변경 구성을 사용하고, 기존 답변·초안·제출본의 본문과 모델 출처는 다시 쓰지 않는다. 프론트의 미적용 입력은 화면 메모리이며 창을 닫기 전에 확인한다.
- 구성별 행 잠금과 `expectedRevision`을 함께 검사한다. 충돌은 `409 REVISION_CONFLICT`와 `currentRevision`으로 알린다. 비교 이후 다른 수정이 있으면 적용도 거부한다. 자동 덮어쓰기·재시도는 하지 않는다.
- 기존 구성은 마이그레이션에서 BASELINE으로 기록한다. 이후 생성·변경·복원마다 전체 값, 작성자, 사유, 기준 버전, 복원 원본 ID를 기록한다. DB 트리거로 이력 수정·삭제를 막는다. 복원은 과거 값을 현재 설치 정책으로 다시 검증하는 새 변경이다.
- 연결 시험은 고정 합성 문장만 전송한다. 실제 서버에서는 업무 `fake` 모드와 관계없이 실제 모델을 시험한다. 최대 512 토큰, 구성 시간 제한과 30초 중 작은 값, 재시도 0회, 프로세스당 동시 2건으로 제한한다. DB 트랜잭션을 외부 호출 중 유지하지 않는다.
- 시험 자원 생성 `201`은 연결 성공을 뜻하지 않는다. 응답의 `status`와 `outcome`으로 성공·키 미설정·인증 실패·시간 초과·빈 응답·서비스 오류를 구분한다. 원격 응답 원문과 예외 원문은 저장·노출하지 않는다. 시험 중 구성이 바뀌면 결과를 오래된 것으로 표시한다.
- 프론트 독립 모의 API는 외부 연결을 하지 않고 `FAILED / SIMULATED`를 명시한다. 실제 연결 성공을 가장하지 않는다.

## 실제 연결에서 발견한 호환 문제

현재 사용하는 Spring AI 2.0.1의 OpenAI SDK는 이전 방식과 달리 `/v1`을 자동 추가하지 않는다. [Spring AI 공식 연결 설정](https://docs.spring.io/spring-ai/reference/api/chat/openai-chat.html)을 확인하고 실제 도커 호출로 검증했다. 호스트 루트와 기존 OpenRouter `/api` 주소에는 호출 시 `/v1`을 붙인다. 이미 명시한 `/v1`과 사용자 지정 경로는 유지한다. 저장된 값과 과거 이력은 바꾸지 않으며 업무 호출과 연결 시험에서 같은 처리를 사용한다.

새 도커 볼륨의 업로드 폴더가 root 소유여서 합성 파일 업로드가 실패하는 문제도 확인했다. 이미지에 `/data/storage`를 app 소유로 준비해 새 볼륨에 올바른 소유권을 복사한다. 기존 볼륨의 소유권을 자동 변경하지 않는다.

## 검증과 한계

실제 GPT-4o mini·Gemma 3 27B의 네 용도 호출, 신청·기존 응답 보존, 권한 차단, 충돌, 복원, 이력 페이지를 도커에서 확인했다. [검증 기록](../LLM_ADMINISTRATION_20261110.md) 참고. 연결 성공은 개별 업무의 답변 품질 평가나 모든 모델 옵션의 호환성 보장이 아니다. 모델 목록·키 값·허용 호스트를 외부에서 자동 수집하거나 수정하지 않는다.
