# 항목별 답변 권한·형식 검증

2026-11-10 · Back #23 / Front #64

신청 접근·배정 권한 검사에 더해, 신청에 고정된 게시본의 `askRole`과 `type`을 검사한다.

| 행위 | 허용 |
|---|---|
| 직접 입력 | 항목의 작성 역할만. ADMIN 우회 없음 |
| 신청자 확인 | APPLICANT 항목의 AI 답변만 |
| 담당자 확인 | 자기 분야 및 APPLICANT 항목. 다른 담당 분야는 불가 |
| AI 추천 적용 | APPLICANT 항목만, 형식 검사 후 AI_INFERRED·미확정 |

개별·일괄 저장, 확인, AI 제안, 분석 적용, 사업 초기값과 연장 신청 미리 채움에 공통 규칙을 적용한다.
담당자 항목은 신청자의 미리 채움으로 확인 완료가 되지 않는다. 기존 자료를 일괄 수정하지는 않는다.

형식은 TEXT/LONG_TEXT 1~4000자, BOOLEAN `true`/`false`/`예`/`아니요`, NUMBER 부호·소수점 있는 십진수,
DATE_RANGE `YYYY-MM-DD~YYYY-MM-DD`(실제 달력·종료일 순서 검사)다. 종료일 생략 및 기존 `상시`/`종료일 없음` 표현을 허용한다.
선택 항목의 기존 `미해당` 표현은 호환하되 필수 항목에서는 거부한다.
현재 게시본의 IP·포트 항목은 TEXT이므로 별도의 네트워크 형식 제약을 새로 추정하지 않는다.

권한 위반 403, 값 형식의 업무 규칙 위반 422, DTO 오류 400, 기존 수정본 불일치 409.
담당자 `PATCH /api/reviews/{id}/answers`는 기존 AnswerBatchCommand를 사용한다.
단일 트랜잭션에서 항목별 권한·형식·revision을 검사하며 하나라도 실패하면 전부 취소한다.
기존 화면의 병렬 PUT 요청이 같은 Review revision을 갱신하며 일부 실패하던 문제를 제거한다.
